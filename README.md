# Hartvigsen Llama Farm

Bryndalin Hartvigsen's resume as an interactive llama farm. Drive the farm truck along the road between nine pastures, one per resume section, while the llamas get up to mischief (chalkboard math, chemistry explosions, a dance party...).

- Drive: arrow keys / A-D, on-screen buttons, or click anywhere on the farm
- Honk: H
- Map: M, or click the minimap

Static site: just `index.html`.
